# Day 2 - Microsoft Excel Basics

Today I learned the basic functions and features of Microsoft Excel that are commonly used in data analysis.

## Topics Covered

- MIN function
- MAX function
- AVERAGE function
- COUNT function
- COUNTA function
- Data filtering
- Data sorting
- Fill Handle and AutoFill
- Filling weekdays, years, and formatting
- Formula operators and BODMAS
- Relative, Absolute, and Mixed cell references
- Using Named Ranges
- Formatting data as a Table

## Practice

I practiced these concepts using sample datasets and completed small exercises to understand how each feature works.


## Goal

The goal of today's practice was to build a strong understanding of Excel fundamentals that will help in future data analysis and dashboard projects.
