# Day 3 - Microsoft Excel Intermediate Functions

Today I learned more advanced Excel functions and techniques that are useful for data cleaning, data extraction, and data analysis.

## Topics Covered

- Text to Columns
- Concatenate (Joining Text)
- Flash Fill
- Filling Empty Cells
- SUMIFS - Summarizing Data with Multiple Conditions
- COUNTIFS - Counting Data with Multiple Conditions
- IF Function - Decision Making
- IF with AND & OR - Decision Making Using Multiple Conditions
- ETL (Extract, Transform, Load) Process
- TEXT Function for Data Formatting and Extraction
- SEARCH Function for Extracting Data Using Delimiters

## Practice

I practiced these concepts using sample datasets and solved different business-related Excel problems to improve my understanding of conditional formulas and data transformation techniques.

## Goal

The goal of today's practice was to improve my data cleaning, data transformation, and conditional analysis skills, which are essential for real-world data analysis and business intelligence projects.
