# Day 4 - Microsoft Excel Lookup Functions

Today I learned different lookup functions that are used to find, match, and retrieve data from tables. These functions are widely used in data analysis and reporting.

## Topics Covered

- VLOOKUP using Named Ranges
- IFERROR
- VLOOKUP with Duplicate Data
- HLOOKUP
- INDEX and MATCH

## Practice

I practiced retrieving data from different tables using lookup functions and learned how to handle errors and work with duplicate values. I also compared different lookup methods to understand when each one should be used.


## Goal

The goal of today's practice was to understand lookup functions and improve my ability to retrieve and organize data efficiently in Excel.
