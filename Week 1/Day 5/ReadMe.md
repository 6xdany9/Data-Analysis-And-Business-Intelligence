# Day 5 - Microsoft Excel Advanced Filtering and Data Consolidation

Today I learned how to retrieve specific data, apply advanced filters, and combine information from different data ranges in Excel.

## Topics Covered

- XLOOKUP - Extracting Data with More Capabilities
- FILTER - Getting the Data I Want
- Advanced Filter
- Advanced Filter with Formulas
- Data Consolidation

## Practice

I practiced using XLOOKUP and FILTER to retrieve specific data from tables. I also worked with Advanced Filters, including using formulas as filtering conditions, and learned how to consolidate data from different ranges.


## Goal

The goal of today's practice was to improve my ability to retrieve, filter, and combine data efficiently in Excel.
