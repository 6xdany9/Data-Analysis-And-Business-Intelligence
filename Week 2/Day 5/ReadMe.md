# Week 2 - Day 5 - Power Query

Today I learned the basics of Power Query in Microsoft Excel. I focused on connecting, cleaning, combining, and transforming data from different sources.

## Topics Covered

- Connecting Data using Power Query
- Cleaning Data
- Connecting Multiple Data Sources
- Appending Data from TXT and Access files
- Appending Data from Folders
- Appending Data from Multiple Worksheets
- Merging Data
- Pivoting Data
- Unpivoting Data

## Practice

I practiced importing data from different sources and using Power Query to clean and transform the data. I also learned how to append multiple datasets together and merge related datasets.

## Goal

The goal of today's practice was to understand how Power Query can be used to automate data cleaning and combine data from different sources.
