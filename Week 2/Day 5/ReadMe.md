# Week 2 - Day 5 - Power Query

Today I started learning Power Query in Microsoft Excel. I learned how Power Query can be used to connect, clean, and combine data from different sources.

## Topics Covered

- Connecting Data using Power Query
- Cleaning Data using Power Query
- Connecting Multiple Data Sources
- Appending Data from TXT Files
- Appending Data from Microsoft Access
- Appending Data from Multiple Files in a Folder
- Appending Data from Worksheets

## Practice

I practiced importing data from different sources and using Power Query to clean and combine the data into a single dataset.

## Goal

The goal of today's practice was to understand how Power Query can simplify data preparation and help automate the process of combining and cleaning data.
