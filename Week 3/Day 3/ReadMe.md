# Week 3 - Day 3: Connecting and Transforming Data

Today I learned how to connect, transform, reshape, and combine data using Power Query.

## Topics Covered

* Creating a Live Calendar
* Indexing
* Conditional Columns
* Grouping & Aggregating
* Pivoting & Unpivoting
* Merging Queries

## Practice

I practiced transforming datasets using conditional logic, creating indexes, grouping and aggregating data, reshaping tables through pivoting and unpivoting, and merging multiple queries together.

## Goal

The goal of today's practice was to understand how Power Query can be used to transform raw data into a structured and analysis-ready format, while also learning how different queries can be combined for more efficient data analysis.
